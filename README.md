# l2/d5-vong-lap-tung-buoc — Chạy từng bước vòng lặp for

**Slide:** Bài 2 · "Visualizer vòng lặp" (demo `l2-d5`).

Ba phần của vòng lặp `for` chạy theo thứ tự nào, và đổi từng phần thì kết quả khác ra sao.

```bash
node index.js
git diff l2/d4-vong-lap-long l2/d5-vong-lap-tung-buoc
```

File in ra đúng thứ tự thực thi mà animation trên slide mô tả, rồi chạy ba biến thể:
`i = 0` thay vì `i = 1`, `i < 3` thay vì `i <= 3`, và `i += 2` thay vì `i++`.

Branch tiếp theo: `l2/end`.
