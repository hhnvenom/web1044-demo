# l0/d2-kiem-tra-moi-truong — Kiểm tra môi trường

**Slide:** Bài 0 · "Chuẩn bị môi trường" (demo `l0-d2`).

Chạy được file này nghĩa là Node.js đã cài xong và máy sẵn sàng cho cả môn.

```bash
node index.js
```

Ba lệnh cần kiểm tra thêm trong terminal: `node -v`, `npm -v`, `code -v`.
Thiếu cái nào thì cài lại trước buổi 1.
